At the time the original portable package was built, the GitHub connection
returned HTTP 403 "Resource not accessible by integration" for both source-only
and workflow-containing tree writes; those attempts changed no remote branch.

wheels. The build environment could not run Wine's required IPC sockets, so its
validation covered static PE checks and source Python behavior, not native
Windows or frozen-runtime execution. Its build metadata records these limits
and exact source and dependency hashes. For any subsequently published release,
consult that release's build-info.json and self-test.json for its own validation
results; the earlier portable checks do not establish a Windows CI result.
